# ⚖️ 睿衡引擎（Prudence Engine）

> 银行理财产品导购系统中的**适当性与意图联合决策引擎**  
> —— 将合规风控（适当性管理）与智能营销（意图识别）融合为一体


## 📖 项目简介

睿衡引擎是一套面向银行理财业务场景的**智能决策中台**，核心解决“将适当的产品通过适当的渠道销售给适合的客户”这一监管与业务双重命题。它创新性地将**适当性判定（刚性合规）** 与**意图评分（柔性预测）** 进行分层解耦与联合决策，既确保风险匹配不可逾越，又实现高意向客户的精准触达。

系统提供完整的可视化仪表板、本地文件数据源、多人对比分析等能力，可快速集成到银行导购、财富管理、智能投顾等业务系统中。


## 🎯 核心功能

### 1. 适当性子系统（Suitability）
- **风险匹配矩阵**：基于客户风险等级（C1-C5）与产品风险等级（R1-R5）的硬性匹配规则，支持 `ALLOW` / `RESTRICTED` / `FORBID` 三级判定。
- **扩展规则引擎**：支持高龄保护、首次购买限制、财务承受能力校验、期限匹配等，可灵活扩展。
- **替代推荐**：当产品被禁止时，自动推荐同客户等级下可购买的其他产品。

### 2. 意图子系统（Intent）
- **规则打分 + XGBoost 模型融合**：结合行为特征（浏览、计算器使用、对比等）、交易特征、客户静态特征，输出 0~1 的意图得分。
- **可解释性**：集成 SHAP 值，输出 Top 信号特征，供理财经理理解推荐理由。
- **动态权重**：模型成熟度阶段（new/growing/stable）自动调节规则分与模型分的融合系数。

### 3. 联合决策融合层（Aegis）
- **适当性优先**：任何意图得分都不能推翻适当性判定，禁止推荐永远优先级最高。
- **分层行动**：根据适当性结果（ALLOW / RESTRICTED / FORBID）和意图得分（高/中/低），输出 `PROACTIVE_CLOSING`（促单）、`NURTURE_CONTENT`（培育）、`LOW_PRIORITY`（暂不打扰）或 `HUMAN_REVIEW_REQUIRED`（人工复核）等行动指令。

### 4. 数据服务架构（Nexus）
- **离线层**：T+1 特征计算（Hive/Spark），保证适当性判定的稳定性。
- **实时层**：Kafka + Flink + Redis 实时特征聚合，满足意图打分的时效性需求。
- **在线层**：特征拼接 → 适当性判定 → 意图打分 → 融合决策，全程可追溯。


## 🖥️ 可视化仪表板（Streamlit UI）

睿衡引擎内置了功能完整的 Streamlit 可视化仪表板，无需额外前端开发即可使用全部决策能力。

### 📋 单客户决策模式

- **客户/产品选择**：从当前数据源加载的客户列表和产品列表中选择。
- **客户画像展示**：显示客户姓名、风险等级、年龄、可投资资产、最长锁定期等信息。
- **产品详情展示**：显示产品名称、风险等级、锁定期、起购金额、产品类型。
- **决策结果展示**：醒目颜色展示决策动作（促单/培育/暂不打扰/人工复核/拦截），并显示适当性等级、意图得分、决策原因、决策耗时。
- **适当性判定详情**：展示矩阵匹配结果（ALLOW/RESTRICTED/FORBID）、匹配规则，以及替代推荐产品列表。
- **意图评分分解**：规则分、模型分、融合分三列展示，进度条直观显示意图得分，并展示 Top 信号特征及其贡献值。
- **风险匹配矩阵热图**：5×5 矩阵全览，星标定位当前客户-产品组合。

### 👥 多人对比模式

- **批量选择**：同时选择多个客户（最多 5 个）和多个产品，一键执行批量决策。
- **对比明细表格**：展示所有组合的决策动作、适当性等级、意图分、规则分、模型分、主要信号。
- **可视化图表**：
  - 各客户-产品意图得分对比柱状图
  - 规则分、模型分、意图分分组对比图
  - 客户画像雷达图（风险等级、年龄、资产、锁定期归一化对比）
  - 适当性等级分布饼图
  - 决策动作分布条形图
  - 主要信号频次统计
  - 规则分 vs 模型分散点图
- **数据导出**：一键下载对比结果为 CSV 文件。

### 📂 数据源管理

- **本地文件上传**：支持 CSV、Excel（含多 Sheet）、JSON 格式，自动识别客户表、产品表、意图特征表。
- **数据源状态显示**：实时显示当前数据源类型、客户数量、产品数量。
- **重置默认数据**：一键切换回内置模拟数据。
- **示例模板下载**：提供标准 JSON 格式示例，帮助快速了解数据结构。

### 📜 历史记录与报告导出

- **决策历史记录**：侧边栏保存所有历史决策，点击可回溯查看。
- **HTML 报告导出**：生成包含客户信息、产品信息、决策结果、匹配矩阵、评分分解的完整报告，可直接打印为 PDF。
