# 客户画像、价值情景与因子分析口径

## 统一分析对象

每条记录是一位客户，产品与当前策略是分析上下文。散点、雷达、榜单、贡献拆解、敏感性和服务计划均复用客户 ID。客户搜索和适当性筛选不重新归一化评分，也不重新拟合因子模型。更换数据源会清除当前选择、情景和服务计划。

主图点选查看客户；工具栏支持框选、套索。完成圈选后可在“服务计划”选择只使用圈选客户。切回图表工具栏的平移模式可继续单点查看。右侧客户选择器提供重叠点与键盘操作的替代入口；手动选择会清除旧圈选。变更产品、指标或有效样本后旧图事件不复用。

## 六维观察评分 v1

设 S(x,a) = 100 × min(log(1+x) / log(1+a), 1)，x 必须是非负有限观测值。以下锚点是透明的工程约定，不是经过业务标签校准的参数。

| 维度 | 计算式 | 所需数据 |
|---|---|---|
| 近期活跃 | [S(浏览次数,20) + 100 × 2^(−购买间隔/30)] / 2 | beh_view_cnt_7d, txn_days_since_last_purchase |
| 决策投入 | [S(计算器次数,5) + S(比较次数,10)] / 2 | beh_calculator_use_cnt, beh_compare_cnt |
| 互动响应 | 50×打开率 + 0.25×S(顾问联系频次,5) + 25×接受标记 | interact_push_open_rate_30d, interact_advisor_contact_freq, interact_last_script_accepted |
| 风险适配 | 100 × min(客户风险序数/产品风险序数,1) | C1–C5, R1–R5 |
| 资金余量 | 100 × max(1−产品起投金额/可用资产,0)；资产为零时为 0 | assets, min |
| 期限匹配 | 100 × min(可接受期限/锁定期限,1)；锁定期限为零时为 100 | period, lock |

关注度 E 为前三维均值，产品匹配度 F 为后三维均值。综合观察分 = 100 × (E/100)^α × (F/100)^(1−α)，α 默认为 0.5，可在 0.1–0.9 间调整。缺失或无效行为值不会补零；相应维度及综合分留空。打开率与接受标记接受 0–1 的输入；原始观测表保留得分依据。资金余量衡量产品起投压力，计划配置金额另由硬规则检查。

雷达虚线是当前筛选群体各维度的中位数，缺失按列忽略，不能解释为平均客户的联合画像。坐标固定为 0–100。散点 60 分参考线仅辅助阅读；风险序数的比值展示不替代离散适当性规则。没有“分越高客户越好”的人格、信用或购买概率解释。

敏感性图在当前筛选群体中逐一改变 α，采用并列最小名次。它展示权重选择的影响，不是置信区间。

## 可编辑年度价值情景

所有利率输入以百分数展示、以小数计算；金额单位元，期限单位天。默认 1.5% 存款、4% 贷款、2.5% FTP、3.5% 理财毛收益、0.5% 理财年费率仅为模拟参数。理财毛收益可设为负值（最低 −100%）以观察下行情景。

设可用资产 A，存款比例 d，理财比例 w，必须 d+w ≤ 1。存款 D=A×d；计划理财 W*=A×w。适当性引擎用 max(起投金额,W*) 重新执行金额约束，并保留客户风险、高龄、首购和期限等原有规则。只有 ALLOW 且 W* 达起投金额时 W=W*，否则 W=0。未配置资金 U=A−D−W，不自动转移，始终展示。

贷款余额 L 优先使用客户表可选字段 loan_balance；真实零余额保留为零。缺失余额使用用户明确可编辑的统一假设（默认零），并标记“情景假设”。存款和理财金额由资产分配假设生成，不是观察到的真实账户余额。贷款余额代表情景或存量贷款，不生成授信审批建议。

- 存款利差贡献：D×(FTP−存款利率)
- 贷款利差贡献：L×(贷款利率−FTP)
- 理财费用贡献：W×理财年费率
- 简化预期损失：L×年度违约概率假设×违约损失率假设
- 年度贡献：前三项之和−预期损失−年度服务成本
- 客户年度净收支情景：D×存款利率 + W×(理财毛收益率−年费率) − L×贷款利率

最后一项是客户口径，前五项为机构口径，不能混用。假设理财费率由客户支付且全额形成机构费用收入。理财毛收益率不会被误算成机构收入。负贡献与亏损情景保留负值。

假设余额与年化利率保持一年，不含本金变动、复利、税费、净值波动、资本占用、违约后利息调整或客户留存；FTP 为单一利率，未实现期限曲线和流动性溢价。锁定期影响适当性，不会自动把年度口径改为持有期收益。此功能不声称实际利润、购买转化率、风险调整资本收益或 CLV。

产品风险、期限和起投额的修改只改变本次看板情景；原数据源及 API 配置不被写回。下载情景参数便于记录当前假设。

## 因子分析：真正的共同因子模型

输入为八项原始观测：可用资产、浏览次数、计算器使用、比较次数、购买间隔、推送打开率、顾问联系频次、平均持有期。除打开率外均取 log(1+x) 减弱长尾，完整案例上按总体标准差（ddof=0）标准化。

删除含缺失/无效值的客户，报告数量；剔除常量列。至少需要 3 个变化变量及 max(30,5×变量数) 位完整客户，因子数可选 2 或 3 且小于变量数。该样本门槛仅为原型保护条件，不保证统计可靠性。完全共线或不收敛时停止并解释，不伪造投影。

模型 z = Lf + ε，f 的协方差为单位阵，ε 的协方差为对角阵。使用 sklearn FactorAnalysis 的最大似然估计、LAPACK SVD 与 Varimax 旋转。SVD 是计算手段，不能把此模型解释成 PCA。以每个因子绝对最大载荷的方向固定符号，便于同一数据下复现。

- 载荷：变量与潜在共同结构的关系，正负均有意义。
- 共同度：该变量的载荷平方和。
- 独特方差：模型估计的变量特定噪声方差。
- 重建误差：||R−(LLᵀ+diag(ψ))||F / ||R||F，R 使用标准化数据的总体协方差。
- 条件数：相关矩阵数值稳定性的诊断，超过 1000 时提示共线风险。

因子模型拟合当前全数据源一次，再把筛选客户投影到同一坐标。因子无自然“好坏”顺序，名称只列绝对载荷最大的观测变量，不替代领域解释；未输出伪造的因子显著性、KMO 或预测精度。需要真实数据上的重复抽样和外部验证才能支持更强结论。

## 服务计划和数值库

服务计划沿用 analytics.optimize_allocation：0–1 整数规划，每位客户最多一次，受预算、触达人数和产品容量约束。仅完整画像且 ALLOW、目标效用为正的候选进入求解。当前只分配所选产品。输入签名涵盖候选、目标和约束；任一变化后隐藏旧结果，要求重新生成。

若以年度贡献为目标，这是存量/情景规模的排序目标，不能解释为触达的增量利润。单次触达成本与年度服务成本分别计量；没有转化概率校准，不伪造服务 ROI。仅输出本地计划，不实际触达客户或执行交易。

analytics.py 中的 PCA、矩阵秩/SVD/重建、零和 minimax、双矩阵纯策略 Nash 等通用函数及测试保留，用于后续研究；统一看板不再展示无客户上下文的独立实验页。

## 数据与验证

模拟客户使用 seed=42，可复现且明确标注。导入限制 10 MB/文件、20,000 行/表；验证字段、ID 唯一性、有限非负数值及风险编码。可选 loan_balance 允许空值，但拒绝无效字符串、负数或无穷值。CSV 导出转义公式前缀；更换数据源清除旧选择和计划。

验证覆盖评分单调性和边界、缺失传播、筛选不改变分数、金额守恒、利率敏感性、机构/客户收益隔离、实际配置适当性、因子结构恢复和异常输入、点击稳定 ID 及页面参数联动。研究来源见 [研究映射](customer-scoring-research.md)。
