# 分析方法与验证口径

## 数据与可视化

统计页每位客户只出现一次，不将多个客户–产品决策重复计入样本量。缺失、无法转为数值的内容与无穷大被标为缺失，不用 0 填充统计数据。分布使用有效观测；相关系数使用每对变量的完整观测，至少 3 条，并单独显示样本数。常量列相关系数未定义，保留空值。

UI 默认模拟数据为固定种子 42 的 120 位客户，仅用于展示；原版三位客户可在数据管理恢复。原有命令行与 API 默认数据保持不变。意图模型仍可能使用合成标签训练，得分未经过真实数据校准。禁止组合不运行意图模型，在图表及导出中显示空分数。

导入客户和产品必填字段不得缺失，数值必须有限且非负；年龄与期限为整数。客户 / 产品标识唯一，意图表的客户和特征组合唯一，并校验客户引用与已注册特征。布尔值显式解析，字符串 `false` 不再误判为真。缺失意图特征按 0 补齐进入原型模型；这与统计页保留缺失值是两个不同的计算口径。

## PCA 与线性代数

PCA 采用完整案例法：先排除选定字段中有缺失的行，再去除常量列；至少 3 条完整观测、2 个有变化的字段。变量减样本均值、除以样本标准差（ddof=1）。

对标准化矩阵 Z 进行 SVD：`Z = U S Vᵀ`。主成分得分为 `U S`，特征值为 `S²/(n−1)`，解释方差比例为特征值占总和的比例。载荷为 `V sqrt(特征值)`，表示标准化变量与主成分之间的相关程度。为显示稳定，统一奇异向量的符号；符号本身没有好坏意义。PCA 不等于客户分群或信用评级。

矩阵实验室的秩采用 NumPy 的数值容差；零空间维数为列数减秩。秩亏时条件数显示为无穷。k 阶近似为 `U_k S_k V_kᵀ`，相对误差为 Frobenius 范数 `||A−A_k||/||A||`。零矩阵误差约定为 0，能量保留显示 0；并不表示有信息。只有对称方阵展示实特征值。

## 资源分配

变量 `x_ij ∈ {0,1}` 表示客户 i 是否分配产品 j。仅 `ALLOW` 是可行候选；`RESTRICTED`、`FORBID` 和未知状态均不能分配。

最大化 `Σ u_ij x_ij`，约束：

- 每位客户最多一个产品；
- 每个产品不超过用户设定的容量；
- 总成本不超过预算；
- 总触达人数不超过上限。

UI 的默认效用 `u_ij = 100 × intent_score` 是排序用情景分，不是期望销售额或投资收益。成本单位由用户定义，不是产品最低购买金额。底层函数支持每个组合不同的效用与成本；UI 使用统一服务成本以便解释。产品容量缺失、重复组合及非法数值会报错。候选最多 2,000 个，单次求解限时 10 秒；只有确认最优才展示方案，达到时限不会把可行解称为最优解。允许空方案，预算不足、无可用容量或非正效用时无需强制触达。

预算敏感性曲线在保持其余约束不变时重新求解。修改预算、容量、成本、人数或决策快照后，旧方案不会作为当前结果展示。求解器遇到并列最优时可返回任意等价方案。

## 博弈实验

零和模型中 A 是行玩家收益，列玩家收益是 −A。分别求解最大化保底收益的行策略与最小化最高损失的列策略，两者均为概率分布。报告博弈值 `pᵀAq` 和最佳回应间隙 `max(Aq) − min(pᵀA)`；小间隙是数值正确性的检查。收益允许负值，均衡可能不唯一。

双矩阵模式为任意双方收益矩阵寻找同时为最佳回应的纯策略组合，包含收益并列的情况。无纯策略均衡不等于无混合均衡；当前未实现一般双矩阵的混合均衡枚举。示例收益为教学设定，不描述现实客户行为。

## 验证

运行 `python -m pytest -q`：PCA 与 scikit-learn 参考实现对照并验证重建；整数规划与小规模穷举结果对照；验证匹配硬币、石头剪刀布、鞍点与非零和纯策略均衡；覆盖缺失数据、常量列、零矩阵、重复组合、非法输入与原有安全边界。Streamlit AppTest 覆盖工作区切换、批量决策到资源分配、参数变更与矩阵编辑。

数值实现参考：[NumPy SVD](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)、[SciPy milp](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)、[SciPy linprog](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)。UI 测试使用 [Streamlit AppTest](https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest)。
